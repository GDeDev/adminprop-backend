## Nota de despliegue

Un ambiente `qa` ahora no arranca sin `SITES_PREVIEW_SECRET` de 32+ caracteres ni con `CORS_ORIGINS=*`, y ya no expone Swagger salvo `SWAGGER_ENABLED=true`. Hay que cargarlos en Doppler antes del próximo deploy a qa.

Para completar A-6 hay que cargar `SITES_SERVER_SECRET` (largo y aleatorio, distinto de `SITES_REVALIDATE_SECRET`) en la API y mandarlo como `X-Sites-Secret` desde `apps/sites`. Mientras no esté definida, la API acepta el de revalidación en ese header, así que nada se rompe.
